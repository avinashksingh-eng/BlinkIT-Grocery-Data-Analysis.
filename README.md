- **BlinkIT Grocery Data Excel (version 1) (version 1).xlsb.xlsx** — source workbook for analysis.

- Data cleaning and preparation
- Pivot tables and charts (where included in the workbook)

Explore grocery sales data and practice data analysis workflows in Excel.
